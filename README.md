## Distributional Reinforcement Learning

These are notes and presentation + some code for the Convergence of Reinforcement Learning Algorithms Seminar of Prof.Clemens Heitzinger at TU Berlin Summer 2026.

Specifically, we consider approximating the value function and other quantaties of interest instead of unscalable fully tabular methods and in particular also some recent literature on convergence in metrics that are e.g. not the standard Wassersten or weighted $L^2$ ones as in https://proceedings.neurips.cc/paper_files/paper/2024/file/7371ee6a40da2951303ec7ebdb2150ce-Paper-Conference.pdf.
