\begin{abstract}
These notes give an overview of some theoretical foundations behind approximation based distributional
reinforcement learning and newer methods using differentiable metrics on probability measures. 
We begin with linear value-function approximation in the standard scalar case, then we replace
scalar value functions by the entire return distribution and introduce the two classic representations used in this case, quantile and categorical, of probability distributions.
Then, we go over how these representations can be used in function approximation using deep neural networks.
Finally, we cover the recent research on distributional reinforcement learning using differentiable metrics on probability measures such as the MMD distances or Sinkhorn divergence.  
\end{abstract}

\section*{Preliminaries}

The first part of these notes follow the treatment of distributional reinforcement learning
in \cite{bellemare2023distributional}. We first recall some of the preliminary definitions and results.

\begin{definition}{Finite Markov decision process and policy}{}
A finite Markov decision process is given by
$$
  (\X,\A,\xi_0,P_X,P_R),
$$
where $\X$ is a finite state space, $\A$ is a finite action space, $\xi_0$ is an
initial-state distribution, $P_X(\cdot\mid x,a)$ is the next-state kernel, and
$P_R(\cdot\mid x,a)$ is the reward distribution. A policy is a map
$$
  \pi:\X\to\p(\A),
  \qquad
  x\mapsto\pi(\cdot\mid x),
$$
and the discount factor satisfies $\gamma\in[0,1)$. The markov chain induced by $P_X$ and $\pi$ gives rises to the trajectory measure $P_\pi$.
\end{definition}

Given a policy $\pi$, the trajectory process is
$$
  X_0\sim\xi_0,
  \qquad
  A_t\sim\pi(\cdot\mid X_t),
$$
$$
  R_t\sim P_R(\cdot\mid X_t,A_t),
  \qquad
  X_{t+1}\sim P_X(\cdot\mid X_t,A_t),
  \qquad t\geq0.
$$
Starting from $X_0=x$ and then following $\pi$, define the discounted return
$$
  G^\pi(x)
  =
  \sum_{t=0}^{\infty}\gamma^tR_t.
$$

using this return distribution, one can naturally define the value function that tells us for each state, what the expected return is. 

\begin{definition}{Value function and return distribution}{}
The state-value function is the expected return
$$
  V^\pi(x)
  =
  \E_\pi[G^\pi(x)].
$$
The return distribution at state $x$ is
$$
  \eta_\pi(x)
  =
  \operatorname{Law}(G^\pi(x)).
$$
By definition, we can also write the value function as an integral using the return distribution as a measure. 
$$
  V^\pi(x)
  =
  \int_\R z\,\eta_\pi(x)(\mathrm dz).
$$
\end{definition}

Central to Reinforcement learning is the Bellman operator and its fixed point equation.

\begin{definition}{Bellman operator for scalar values}{}
For a function $V:\X\to\R$, the Bellman operator for policy $\pi$ is
$$
  (\T^\pi V)(x)
  =
  \E_{a\sim\pi(\cdot\mid x)}
  \left[
    \E\left[
      R+\gamma V(X^{\prime})
      \mid X=x,a
    \right]
  \right].
$$
Equivalently, the outer expectation samples the action from the policy and the
inner expectation samples reward and next state from the MDP. The Bellman
equation is
$$
  V^\pi=\T^\pi V^\pi.
$$
\end{definition}

There exists a stronger version of this Bellman equation, which is its distributional variant. 
$$
  A\sim\pi(\cdot\mid x),
  \qquad
  R\sim P_R(\cdot\mid x,A),
  \qquad
  X^{\prime}\sim P_X(\cdot\mid x,A),
$$
the return satisfies
$$
  G^\pi(x)
  \overset{D}{=}
  R+\gamma G^\pi(X^{\prime})
  \qquad\text{given }X=x.
$$
Taking laws gives
$$
  \eta_\pi(x)
  =
  \operatorname{Law}\left(
    R+\gamma G^\pi(X^{\prime})
    \mid X=x
  \right).
$$

\begin{definition}{Distributional Bellman operator}{}
For $r,z\in\R$, define what in \cite{bellemare2023distributional} is called the bootstrap map via
$$
  b_{r,\gamma}(z)=r+\gamma z.
$$
If $\nu\in\p(\R)$ and $Z\sim\nu$, then the pushforward
$(b_{r,\gamma})_\#\nu$ is the law of $r+\gamma Z$:
$$
  (b_{r,\gamma})_\#\nu
  =
  \operatorname{Law}(r+\gamma Z).
$$
For a return-distribution function $\eta:\X\to\p(\R)$, the distributional
Bellman operator is
$$
  (\T^\pi\eta)(x)
  =
  \E_{a\sim\pi(\cdot\mid x)}
  \left[
    \E\left[
      (b_{R,\gamma})_\#\eta(X^{\prime})
      \mid X=x,a
    \right]
  \right].
$$
The return-distribution function $\eta_\pi$ is its fixed point:
$$
\eta_\pi=\T^\pi\eta_\pi.
$$
\end{definition}

For the theory of reinforcement learning particularly important, is that the Bellman operator is a contraction. This is again true for the distributional Bellman operator. However in this case, it is a contraction with respect to the Wasserstein distance.

\begin{theorem}{Wasserstein contraction of the distributional Bellman operator}{}
For $p\in[1,\infty]$, let
$$
  \overline W^\infty_p(\eta,\nu)
  =
  \sup_{x,a}
  W_p(\eta(x,a),\nu(x,a)).
$$
Then
$$
  \overline W^\infty_p(\T^\pi\eta,\T^\pi\nu)
  \leq
  \gamma\,\overline W^\infty_p(\eta,\nu).
$$
\end{theorem}
As also covered earlier in the book, arbitrary distributions cannot be stored on the computer. Hence we need to find some finite dimensional parametrized approximation. 
The two main representations are the following.

\begin{definition}{Finite representations of return distributions}{}
For a probability measure $\eta\in\p(\R)$, let
$$
  F_\eta(t)=\eta((-\infty,t]),
  \qquad
  F_\eta^{-1}(\tau)=\inf\{z\in\R:F_\eta(z)\geq\tau\}.
$$
The two standard representations are:
$$
  \text{categorical:}\qquad
  \eta(x)=\sum_{i=1}^m p_i(x)\delta_{\theta_i},
  \qquad
  p_i(x)\geq0,\quad \sum_{i=1}^m p_i(x)=1,
$$
and
$$
  \text{quantile:}\qquad
  \eta(x)=\frac1m\sum_{i=1}^m\delta_{\theta_i(x)},
  \qquad
  \tau_i=\frac{2i-1}{2m},
  \qquad
  \theta_i(x)\approx F_{\eta(x)}^{-1}(\tau_i).
$$
\end{definition} 
\vspace*{0.5cm}
If $\X$ is large, storing a scalar value for every state is already expensive.
In our case, we would need to store a full probability distribution for every state which is even more expensive. 
Hence, the rest of the notes which are based on \cite{bellemare2023distributional} will focus on value and action value function approximation, starting with the linear case.

\section{Linear Function Approximation}
We first discuss linear approximation for the state-value function
$$
  V^\pi:\X\to\R.
$$
 This section follows parts of Chapter 9 of \cite{bellemare2023distributional}.

\subsection{Function Approximation}

In linear function approximation, we represent the value function as a linear combination of features. Similar to neural networks, the features here are allowed to be nonlinear.

\begin{definition}{State representation and linear value approximation}{}
Let $n\in\N$. A state representation is a mapping
$$
  \phi:\X\to\R^n,
  \qquad
  \phi(x) =
  \begin{pmatrix}
    \phi_1(x) \\ \vdots \\ \phi_n(x)
  \end{pmatrix}.
$$
For $w\in\R^n$, the linear value function approximation is
$$
  V_w(x)=\phi(x)^\top w,
$$
where each $\phi_i$ is a basis function and $\phi_i(x)$ is a feature.
\end{definition}

The model is linear in its weights and
$$
  V_{\alpha w_1+\beta w_2}=\alpha V_{w_1}+\beta V_{w_2},
  \qquad \nabla_w V_w(x)=\phi(x).
$$
For finite $\X$, collect the row vectors $\phi(x)^\top$ in a feature matrix
$\Phi\in\R^{|\X|\times n}$. Then
$$
  V_w=\Phi w,
  \qquad
  \F_\phi=\{\Phi w:w\in\R^n\}.
$$

The same can be done for action value function using $\phi:\X\times\A\to\R^n$ and
$Q_w(x,a)=\phi(x,a)^\top w$. Since we want to focus on what the distributional part changes about the approximation later, we will mostly discuss the state value case. 

\subsection{Optimal Linear Value Function Approximation}

As states above, the equation $$V_w = \Phi w$$ defines a linear system, which won't have a solution in general. 
Instead, a standard way to find the 'best' solution is to minimize the squared error. This can also be done here, however in \cite{bellemare2023distributional} it is mentioned that in RL we are often not equally interested in all states, hence we introduce a weighted least squares loss. \\

So, let $\xi\in\p(\X)$ be the relative importance of the states and define
$$
  \norm{V-V^{\prime}}_{\xi,2}
  =\left(\sum_{x\in\X}\xi(x)(V(x)-V^{\prime}(x))^2\right)^{1/2}.
$$
we are thus interested in the best approximation to $V^\pi$ which solves
$$
  \min_{w\in\R^n}\norm{V^\pi-V_w}_{\xi,2}.
$$
and this is given by a weighted normal equation. 

\begin{theorem}{Weighted normal equation}{}
Let $\Xi=\operatorname{diag}(\xi(x):x\in\X)$. If $\xi$ has full support and
the columns of $\Phi$ are linearly independent, the unique solution is
$$
  w^*=(\Phi^\top\Xi\Phi)^{-1}\Phi^\top\Xi V^\pi.
$$
Thus the state weighting $\xi$ is part of the approximation problem: changing
how often states are sampled generally changes the best attainable weights.
\end{theorem}
The problem is, we can't iterate the Bellman operator since after applying it, we might not have a linear representation anymore. This motivates the following definition of a projected Bellman operator. 

\subsection{The Projected Bellman Operator}

\begin{definition}{Projected Bellman operator}{}
Define the weighted orthogonal projection $\Pi_{\phi,\xi}$ by
$$
  (\Pi_{\phi,\xi}V)(x)=\phi(x)^\top w^*,
  \qquad
  w^*\in\arg\min_{w\in\R^n}\norm{V-V_w}_{\xi,2}.
$$
Approximate dynamic programming iterates
$$
  V_{k+1}=\Pi_{\phi,\xi}\T^\pi V_k.
$$
\end{definition}

Luckily, one can still show that this projected Bellman operator is a contraction and that the fixed point of the projected Bellman operator is close to the best approximation of the true value function. 
Hence, by iteration the Bellman equation like this, we will converge to something that is close to what we are trying to approximate!

\begin{theorem}{Projected Bellman contraction and error bound}{}
Let $\xi_\pi$ be a fully supported steady-state distribution under $\pi$. Then $\Pi_{\phi,\xi_\pi}$ is a nonexpansion in the
$\xi_\pi$-weighted $L_2$ norm. Consequently,
$$
  \norm{\Pi_{\phi,\xi_\pi}\T^\pi V-
  \Pi_{\phi,\xi_\pi}\T^\pi V^{\prime}}_{\xi_\pi,2}
  \leq \gamma\norm{V-V^{\prime}}_{\xi_\pi,2}.
$$
The projected operator has a unique fixed point
$$
  \widehat V^\pi
  =\Pi_{\phi,\xi_\pi}\T^\pi\widehat V^\pi,
$$
Additionally, they show that it holds
$$
  \norm{\widehat V^\pi-V^\pi}_{\xi_\pi,2}
  \leq\frac{1}{\sqrt{1-\gamma^2}}
  \norm{\Pi_{\phi,\xi_\pi}V^\pi-V^\pi}_{\xi_\pi,2}.
$$
which means that the fixed point of the projected Bellman operator is close to the best approximation.
\end{theorem}

\begin{proof}
The proofs follows the argument from \cite[Theorem 9.8]{bellemare2023distributional}.
The transition operator $P^\pi$ is nonexpansive and due to the orthogonality of the projection we have for every $U$,
$$
  U=\Pi_{\phi,\xi_\pi}U+(I-\Pi_{\phi,\xi_\pi})U
$$
is an orthogonal decomposition in the $\xi_\pi$-weighted inner product. Hence,
by Pythagoras,
$$
  \norm{U}_{\xi_\pi,2}^2
  =\norm{\Pi_{\phi,\xi_\pi}U}_{\xi_\pi,2}^2
   +\norm{(I-\Pi_{\phi,\xi_\pi})U}_{\xi_\pi,2}^2,
$$
so $\norm{\Pi_{\phi,\xi_\pi}U}_{\xi_\pi,2}\leq
\norm{U}_{\xi_\pi,2}$. Thus the composition with $\T^\pi$ is a
$\gamma$-contraction. Banach's fixed-point
theorem gives a unique fixed point and convergence of iterating the projected Bellman operator. 

For the error estimate, we use orthogonality of the projection and
$V^\pi=\T^\pi V^\pi$ which yields
$$
\begin{aligned}
 \norm{\widehat V^\pi-V^\pi}_{\xi_\pi,2}^2
 &=\norm{\widehat V^\pi-\Pi_{\phi,\xi_\pi}V^\pi}_{\xi_\pi,2}^2
   +\norm{\Pi_{\phi,\xi_\pi}V^\pi-V^\pi}_{\xi_\pi,2}^2\\
 &\leq\gamma^2\norm{\widehat V^\pi-V^\pi}_{\xi_\pi,2}^2
   +\norm{\Pi_{\phi,\xi_\pi}V^\pi-V^\pi}_{\xi_\pi,2}^2.
\end{aligned}
$$
Rearranging and taking square roots proves the bound.
\end{proof}

However, while this result is nice, performing full Bellman update is expensive. A more practical tool is TD learning which can also be done in the approximate regime.
Since we again want to focus on the distributional side, we dont mention it here and refer to \cite[Chapter 9.4]{bellemare2023distributional} for more details. 

\section{Distributional Value Approximation}

Distributional reinforcement learning replaces the scalar value function by a
return-distribution function. In the following, we use the action-value version of the distributional Bellman
operator defined in the preliminaries. \\

As highlighted in the prelims, the book mainly discusses two ways to parametrize the return distribution.
In both cases we are talking about probability distribution, which do not form a linear space. This is a problem, since we cannot easily define a orthogonal projection.
Hence, for now, we focus on the TD learning of the distributional case. First, we define the linear approximation for both cases.  \\

\begin{definition}{Categorical return-distribution approximation}{}
Fix the support of the atoms
$$
  S=\{\theta_1<\cdots<\theta_m\}\subset\R.
$$
The categorical approximation keeps these locations fixed and learns their probabilities:
$$
  \eta_W(x,a)=\sum_{i=1}^m p_i(x,a;W)\delta_{\theta_i}.
$$
to learn probabilites, one classicly uses the softmax function of the approximated function.
Hence, we have $\ell_i(x,a)=\phi(x,a)^\top w_i$, as our parametrization and 
$$
  p_i(x,a;W)
  =\frac{\exp(\phi(x,a)^\top w_i)}
  {\sum_{j=1}^m\exp(\phi(x,a)^\top w_j)}.
$$
\end{definition}

With the categorical approximation, we have the problem that after a Bellman or even TD update, we might not live on $S$ anymore. Hence we need the following projection.



\begin{definition}{Categorical projection $\Pi_c$}{}
The Bellman update moves the fixed atoms because
$$
  (b_{r,\gamma})_\#\eta(x^{\prime})
  =
  \sum_{j=1}^m p_j(x^{\prime})
  \delta_{r+\gamma\theta_j},
  \qquad
  b_{r,\gamma}(z)=r+\gamma z.
$$
In general, the shifted locations $r+\gamma\theta_j$ are not elements of the
fixed support $S$. The categorical projection
$\Pi_c:\mathcal P(\R)\to\mathcal P(S)$ is defined first on a Dirac mass. If
$\theta_\ell\leq y\leq\theta_{\ell+1}$, then
$$
  \Pi_c\delta_y
  =
  \frac{\theta_{\ell+1}-y}{\theta_{\ell+1}-\theta_\ell}
  \delta_{\theta_\ell}
  +
  \frac{y-\theta_\ell}{\theta_{\ell+1}-\theta_\ell}
  \delta_{\theta_{\ell+1}}.
$$
Values outside the support are clipped to its endpoints:
$$
  \Pi_c\delta_y
  =
  \begin{cases}
    \delta_{\theta_1}, & y\leq\theta_1,\\
    \delta_{\theta_m}, & y\geq\theta_m.
  \end{cases}
$$
The definition is extended linearly to discrete measures. Thus, if
$\theta_\ell\leq r+\gamma\theta_j\leq\theta_{\ell+1}$, the mass
$p_j(x^{\prime})$ contributes
$$
\begin{aligned}
  \bar p_\ell
  &\mathrel{+}=
  p_j(x^{\prime})
  \frac{\theta_{\ell+1}-(r+\gamma\theta_j)}
       {\theta_{\ell+1}-\theta_\ell},\\
  \bar p_{\ell+1}
  &\mathrel{+}=
  p_j(x^{\prime})
  \frac{(r+\gamma\theta_j)-\theta_\ell}
       {\theta_{\ell+1}-\theta_\ell}.
\end{aligned}
$$
The projected categorical Bellman target is therefore
$$
  \Pi_c(b_{r,\gamma})_\#\eta(x^{\prime})
  =
  \sum_{i=1}^m\bar p_i\delta_{\theta_i}.
$$
\end{definition}

The quantile family instead parametrizes $\nu \in \mathcal{P}(\R)$ with
cumulative distribution function $F_\nu$, through its quantile function by
$$
  F_\nu^{-1}(\tau)
  =
  \inf\{z\in\R : F_\nu(z)\geq \tau\},
  \qquad \tau\in(0,1).
$$

in the quantile representation, we try and approximate the positions of fixed quantile levels. 

\begin{definition}{Quantile return-distribution approximation}{}
The general form of linear quantile return distribution approximation is 
$$
  \theta_i(x,a)=\phi(x,a)^\top w_i,
  \qquad w_i\in\R^d.
$$
Equivalently, with $W=(w_1,\ldots,w_N)\in\R^{d\times N}$,
$$
  \eta_W(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N
  \delta_{\phi(x,a)^\top w_i}.
$$
In particular, we fix the probabilities to be equal, but allow the atom positions to change.
\end{definition}

\subsection{Signed categorical approximation}

For the theoretical analysis of linear categorical approximation, we now want to allow signed measures. 
This will allow us to analyze the space of measures as a linear space equipped with a distance and as such also will allows us to define a linear projection operator.
In turn this will in the end allow us to see if in the linear categorical setting, we are working with a contraction (if we work in the categorical representation defined below).

\begin{definition}{Signed categorical family}{}
For the fixed support $S=\{\theta_1,\ldots,\theta_m\}$, define
$$
  \mathcal F_{S,m}
  =
  \left\{
    \sum_{i=1}^m p_i\delta_{\theta_i}
    \ \middle|\
    p_i\in\R,\ \sum_{i=1}^m p_i=1
  \right\}.
$$
The coefficients still have total mass one but may be negative. The associated
return-distribution functions form the space of maps from the state space to these signed measures:
$$
  \mathcal F_{S,m}^{\X}
  =
  \{\eta:\X\to\mathcal F_{S,m}\}.
$$
\end{definition}

Now, we will not use the softmax anymore, but instead we will just directly use $\phi(x)^\top w_i$ as the probabilites, although centering them to ensure that they sum to one. 
$$
  p_i(x)
  =
  \frac1m+\phi(x)^\top w_i
  -\frac1m\sum_{j=1}^m\phi(x)^\top w_j .
$$
Then $\sum_i p_i(x)=1$ for every $x$, while individual $p_i(x)$ may be
negative. We denote the resulting finite dimensional measure space by
$$
  \mathcal F_{\phi,S,m}
  =
  \left\{
    x\mapsto\sum_{i=1}^m p_i(x)\delta_{\theta_i}
    \ \middle|\
    w_1,\ldots,w_m\in\R^d
  \right\}.
$$

Now, we need a distance on this space, which the Cramer distance defined earlier in the book provides.

\begin{definition}{Cram\'er geometry for signed measures}{}
For signed measures $\nu,\nu^{\prime}$ of total mass one, define
$$
  \ell_2^2(\nu,\nu^{\prime})
  =
  \int_\R\left(F_\nu(z)-F_{\nu^{\prime}}(z)\right)^2\,\mathrm dz,
  \qquad
  F_\nu(z)=\nu((-\infty,z]).
$$
Let
$$
  \mathcal M_{\ell_2,1}(\R)
  =
  \left\{
    \nu:\nu(\R)=1,\ \ell_2(\nu,\delta_0)<\infty
  \right\}.
$$
For return-distribution functions, the stationary-state-weighted distance is
$$
  \ell_{\xi,2}^2(\eta,\eta^{\prime})
  =
  \sum_{x\in\X}\xi(x)
  \ell_2^2\!\left(\eta(x),\eta^{\prime}(x)\right).
$$
\end{definition}

Now, there are two distinct approximation errors after a Bellman update. First,
$(\T^\pi\eta)(x)$ need not be supported on $S$, so the categorical projection
$\Pi_c$ moves its mass back to the fixed support. Second, even
$\Pi_c\T^\pi\eta$ need not have probabilities that are linear in the features,
so a feature projection is required:
$$
  \Pi_{\phi,\xi,\ell_2}\widetilde\eta
  \in
  \arg\min_{\eta^{\prime}\in\mathcal F_{\phi,S,m}}
  \ell_{\xi,2}(\widetilde\eta,\eta^{\prime}).
$$
Consequently, the approximate Bellman operator we need to consider here is the double projection
$$
  \Pi_{\phi,\xi,\ell_2}\Pi_c\T^\pi.
$$

\begin{lemma}{Bellman and categorical bounds
\cite[Lemma 9.14]{bellemare2023distributional}}{}
Let $\xi_\pi$ be a fully supported stationary distribution under $\pi$. For
$\eta,\eta^{\prime}\in\mathcal M_{\ell_2,1}(\R)^\X$,
$$
  \ell_{\xi_\pi,2}(\T^\pi\eta,\T^\pi\eta^{\prime})
  \leq
  \sqrt{\gamma}\,\ell_{\xi_\pi,2}(\eta,\eta^{\prime}).
$$
Moreover, the pointwise categorical projection is nonexpansive:
$$
  \ell_{\xi_\pi,2}(\Pi_c\eta,\Pi_c\eta^{\prime})
  \leq
  \ell_{\xi_\pi,2}(\eta,\eta^{\prime}).
$$
\end{lemma}

\begin{lemma}{Linear feature projection nonexpansive
\cite[Lemma 9.16]{bellemare2023distributional}}{}
For $\eta,\eta^{\prime}\in\mathcal F_{S,m}^{\X}$,
$$
  \ell_{\xi_\pi,2}
  \left(
    \Pi_{\phi,\xi_\pi,\ell_2}\eta,
    \Pi_{\phi,\xi_\pi,\ell_2}\eta^{\prime}
  \right)
  \leq
  \ell_{\xi_\pi,2}(\eta,\eta^{\prime}).
$$
\end{lemma}

With these two lemmas in hand, the final result will just be a simple combination of the obtained bounds which finally shows that the double projected Bellman operator is a contraction with the same $\sqrt{\gamma}$ constant as the original Bellman operator w.r.t to the cramer geometry.

\begin{theorem}{Doubly projected categorical Bellman contraction
\cite[Theorem 9.13]{bellemare2023distributional}}{}
The operator
$$
  \Pi_{\phi,\xi_\pi,\ell_2}\Pi_c\T^\pi
$$
is a $\sqrt{\gamma}$-contraction in $\ell_{\xi_\pi,2}$. Therefore it has a
unique fixed point in $\mathcal F_{\phi,S,m}$.
\end{theorem}

\begin{proof}
The Bellman operator contributes the strict $\sqrt{\gamma}$ factor, while both
projections are nonexpansive. Hence
$$
\begin{aligned}
  &\ell_{\xi_\pi,2}
  \left(
    \Pi_{\phi,\xi_\pi,\ell_2}\Pi_c\T^\pi\eta,
    \Pi_{\phi,\xi_\pi,\ell_2}\Pi_c\T^\pi\eta^{\prime}
  \right)\\
  &\quad\leq
  \ell_{\xi_\pi,2}(\Pi_c\T^\pi\eta,\Pi_c\T^\pi\eta^{\prime})\\
  &\quad\leq
  \ell_{\xi_\pi,2}(\T^\pi\eta,\T^\pi\eta^{\prime})\\
  &\quad\leq
  \sqrt{\gamma}\,\ell_{\xi_\pi,2}(\eta,\eta^{\prime}).
\end{aligned}
$$
Banach's fixed-point theorem gives existence and uniqueness of the fixed
point.
\end{proof}

\section{Distributional Approximate TD}

The categorical TD learning is very similar to the scalar case, hence we focus on the quantile case and refer to \cite[Chapter 10]{bellemare2023distributional}. \\

For the quantile case, if we are given a policy $\pi$, sample a transition and next action
$$
  (x_t,a_t,r_t,x^{\prime}_t,a^{\prime}_t),
  \qquad a^{\prime}_t\sim\pi(\cdot\mid x^{\prime}_t).
$$
The distributional Bellman target is represented by the $N$ target atoms
$$
  y_j
  =
  r_t+\gamma\theta_j(x^{\prime}_t,a^{\prime}_t),
  \qquad j=1,\ldots,N.
$$
The current prediction at $(x_t,a_t)$ has atoms
$$
  z_i=\theta_i(x_t,a_t),
  \qquad i=1,\ldots,N.
$$
\begin{definition}{Quantile TD loss}{}
Quantile regression uses the asymmetric absolute loss
$$
  \rho_\tau(u)
  =
  u\bigl(\tau-\1_{\{u<0\}}\bigr).
$$
The empirical Quantile TD loss is then
$$
  L(W)
  =
  \frac{1}{N}
  \sum_{i=1}^N
  \sum_{j=1}^N
  \rho_{\tau_i}(y_j-z_i).
$$
The residual $y_j-z_i$ compares an atom of the Bellman target distribution with
the predicted $\tau_i$-quantile at the current state and chosen action. Minimizing this
loss moves $\eta_W(x_t,a_t)$ towards the bellman target
$$
  \frac{1}{N}\sum_{j=1}^N
  \delta_{r_t+\gamma\theta_j(x^{\prime}_t,a^{\prime}_t)}
  =
  (b_{r_t,\gamma})_{\#}\eta_W(x^{\prime}_t,a^{\prime}_t).
$$
\end{definition}

For linear quantiles, a subgradient (which we need since its not differentiable at 0) update is
$$
  w_{i,t+1}
  =
  w_{i,t}
  +
  \alpha_t
  \left(
    \frac{1}{N}\sum_{j=1}^N
    \bigl(\tau_i-\1_{\{y_j < z_i\}}\bigr)
  \right)
  \phi(x_t,a_t),
  \qquad i=1,\ldots,N.
$$
This is the exact analogue of the semi-gradient TD update:
$$
  \delta_t
  =
  r_t+\gamma Q_{w_t}(x^{\prime}_t,a^{\prime}_t)-Q_{w_t}(x_t,a_t)
$$

If we are not given a policy, we can just greedily sample it at the next state.
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac{1}{N}\sum_{j=1}^N \theta_j(x^{\prime},a^{\prime}).
$$
The target atoms become
$$
  y_j=r+\gamma\theta_j(x^{\prime},a^*(x^{\prime})),
  \qquad j=1,\ldots,N.
$$

\section{Deep Distributional Reinforcement Learning}

Now, instead of a linear feature representation, we use a neural network
$$
  \psi_\omega(x)\in\R^d,
$$
where $\omega$ are the parameters and the final layers produce a distributional prediction in some sense, i.e. either quantiles or probabilities for the categorical case. \\

\subsection{QR-DQN}

QR-DQN is the deep version of Quantile TD. It
uses a neural network to output $N$ quantile locations for each action:
$$
  \theta_i(x,a;\omega),
  \qquad i=1,\ldots,N,\ a\in\A.
$$
For each state-action pair, the predicted return distribution is
$$
  \eta_\omega(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N
  \delta_{\theta_i(x,a;\omega)}.
$$

As in DQN, QR-DQN uses two sets of parameters. This is needed because the target network is the same as our current one, hence we fix the target parameters for a couple of iterations always. 
For a transition
$
  (x,a,r,x^{\prime}),
$
the greedy next action is selected by
the mean of the target-network distribution:
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac{1}{N}\sum_{j=1}^N
  \theta_j(x^{\prime},a^{\prime};\bar{\omega}).
$$
The target quantile atoms are
$$
  y_j
  =
  r+\gamma(1-d)\theta_j(x^{\prime},a^*(x^{\prime});\bar{\omega}),
  \qquad j=1,\ldots,N.
$$
The online prediction atoms for the sampled action are
$$
  z_i
  =
  \theta_i(x,a;\omega),
  \qquad i=1,\ldots,N.
$$
\begin{definition}{Quantile Huber loss}{}
QR-DQN replaces the nonsmooth quantile loss $\rho_\tau$ by the quantile Huber
loss; see \cite[Chapter 10]{bellemare2023distributional}. Define
$$
  \mathcal{L}_\kappa(u)
  =
  \begin{cases}
    \frac{1}{2}u^2, & |u|\leq \kappa,\\
    \kappa\left(|u|-\frac{1}{2}\kappa\right), & |u|>\kappa,
  \end{cases}
$$
and
$$
  \rho_\tau^\kappa(u)
  =
  \left|\tau-\1_{\{u<0\}}\right|
  \frac{\mathcal{L}_\kappa(u)}{\kappa}.
$$
For small residuals the loss is quadratic and gives smoother gradients, in particular it is differentiable at 0. 
For large residuals it behaves linearly, preventing exploding gradients.
\end{definition}

\begin{figure}[ht]
  \centering
  \includegraphics[width=0.78\linewidth]{../Presentation/images/2026-07-01-11-07-18.png}
  \caption{Quantile Huber losses for several quantile levels.}
  \label{fig:quantile-huber-loss}
\end{figure}

\begin{definition}{QR-DQN training objective}{}
QR-DQN minimizes the pairwise quantile Huber loss
$$
  L_{\mathrm{QR}}(\omega)
  =
  \frac{1}{N}
  \sum_{i=1}^N
  \sum_{j=1}^N
  \rho_{\tau_i}^{\kappa}(y_j-z_i),
$$
with quantile levels
$$
  \tau_i=\frac{2i-1}{2N}.
$$
If we have acess to a minibatch $\mathcal{B}$ sampled from replay memory, the objective is just the sum over the above single transition loss. 
\end{definition}

For the categorical case, the most notable deep variant is C51 which essentially uses the same ideas that the linear approximation in both the scalaer and distributional versions use, hence we will not discuss it here. For more details, see \cite[Chapter 10.2]{bellemare2023distributional}.

\section{Particle Distributional DQN}
Now we will discuss some recent work on Distributional DQN that does not utilize a fixed parametrization of the return distribution. Instead, a particle representation is used where we just take the empirical measure of multiple samples.

$$
  \eta_\omega(x,a)
  =
  \frac1N\sum_{i=1}^N\delta_{z_i(x,a;\omega)}
$$
For such methods, the common template is:
\begin{enumerate}
  \item choose a divergence or metric $d$ between probability measures,
  \item study whether the distributional Bellman operator contracts under the
  induced supremum metric which takes the maximum difference over the states and actions
  $$
    \bar d(\eta,\nu)=\sup_{x,a}d(\eta(x,a),\nu(x,a)),
  $$
  \item use the empirical version of $d$ as a differentiable DQN loss.
\end{enumerate}
The last point is important, since the standard Wasserstein distance is not differentiable and hence not that well suited for this problem. 

\subsection{MMD-DQN}

This section follows \cite{nguyen2020moment}. The maximum mean discrepancy (MMD) is a metric on probability measures that is induced by a reproducing kernel Hilbert space. 
Depending on the choice of the kernel, many different metrics can be constructed. However not all kernels induce a metric. 

\begin{definition}{Kernel mean embedding and maximum mean discrepancy}{}
Let $k:\R\times\R\to\R$ be a continuous positive-definite kernel and let
$\Hcal_k$ be its reproducing kernel Hilbert space. For a probability measure
$\mu$, define the kernel mean embedding
$$
  \psi_\mu
  =
  \int k(z,\cdot)\,\mu(\mathrm dz)
  \in\Hcal_k.
$$
The maximum mean discrepancy is
$$
  \MMD_k(\mu,\nu)
  =
  \norm{\psi_\mu-\psi_\nu}_{\Hcal_k}.
$$
Equivalently, if $Z,Z^{\prime}\sim\mu$ and
$Y,Y^{\prime}\sim\nu$ are independent, then
$$
  \MMD_k^2(\mu,\nu)
  =
  \E k(Z,Z^{\prime})+\E k(Y,Y^{\prime})-2\E k(Z,Y).
$$
If the kernel is characteristic, the embedding is injective, and
$\MMD_k(\mu,\nu)=0$ implies $\mu=\nu$. With this, the MMD is really a metric. 
\end{definition}

\begin{example}{Characteristic kernels}{}
Standard characteristic kernels on $\R^d$ include
\begin{align*}
  \text{Gaussian:}\quad
  &k(x,y)=\exp\!\left(-\frac{\norm{x-y}^2}{2\sigma^2}\right),\\
  \text{Laplace:}\quad
  &k(x,y)=\exp\!\left(-\frac{\norm{x-y}}{\sigma}\right),\\
  \text{inverse quadratic:}\quad
  &k(x,y)=\left(c^2+\norm{x-y}^2\right)^{-\beta},
\end{align*}
where $\sigma,c,\beta>0$. By contrast, the linear kernel
$k(x,y)=x^\top y$ is not characteristic.
\end{example}

The papers \cite{nguyen2020moment,sun2022regularized} additionally use
$$
  k_\alpha(x,y)=-\norm{x-y}^{\alpha},
  \qquad 0<\alpha<2,
$$
and call it an \emph{unrectified kernel}. 
Despite this function not being a kernel, as it is not positive definite it still induces a MMD metric for probabilty measures. Which we show in the follwing. 
\begin{theorem}{Unrectified Kernel induces MMD metric}{}
  For $0<\alpha<2$, the function $k_\alpha$ is conditionally positive definite on coefficients whose sum is zero. Hence, for probability measures $\mu,\nu$,
  $$
    \MMD_{k_\alpha}^2(\mu,\nu)
    =
    -\E\norm{Z-Z^{\prime}}^{\alpha}-\E\norm{Y-Y^{\prime}}^{\alpha}+2\E\norm{Z-Y}^{\alpha}
    \geq 0,
  $$
  where $Z,Z^{\prime}\sim\mu$ and $Y,Y^{\prime}\sim\nu$ are independent. In particular, $MMD_{k_\alpha}$ is a metric.
\end{theorem}

\begin{proof}
  Most of this proof is utilizing the theory from \cite{sejdinovic2013equivalence}.
  Firstly, one can show directly that 
$$\sum_{i,j=1}^{N}\alpha_i \alpha_j \|x_i-x_j\|^2 \leq 0$$
for any $(\alpha_i)$ with $\sum_{i=1}^{N}\alpha_i=0$. This is what \cite{sejdinovic2013equivalence} calls a negative type metric. 
For this, in Proposition 3.1 they show that also $\|\cdot - \cdot\|^\alpha$ is a negative type metric for any $0<\alpha<2$.
This implies that $k_\alpha$ is conditionally positive definite on coefficients whose sum is zero.
Additionally, Lemma 12 of \cite{sejdinovic2013equivalence} shows that for any
negative-type semimetric, the distance-induced function
$$
  k_{x_0}(x,y)
  =
  \frac12\left(
    \norm{x-x_0}^\alpha
    +\norm{y-x_0}^\alpha
    -\norm{x-y}^\alpha
  \right)
$$
is a valid kernel and hence induces an RKHS. Additonally, they show that this kernel is charactaristic and hence MMD is a metirc for this Kernel. 
When writing out this MMD, we have 
$$
MMD_{k_{x_0}}^2(\mu,\nu) = \E k_{x_0}(Z,Z^\prime) + \E k_{x_0}(Y,Y^\prime) - 2\E k_{x_0}(Z,Y)
$$  
now when expanding the definiton of $k_{x_0}$, we have
\begin{align*}
  MMD_{k_{x_0}}^2(\mu,\nu)
  &= \frac12\E \norm{Z-x_0}^\alpha
   + \frac12\E \norm{Z^\prime-x_0}^\alpha
   - \frac12\E \norm{Z-Z^\prime}^\alpha\\
  &\quad+ \frac12\E \norm{Y-x_0}^\alpha
   + \frac12\E \norm{Y^\prime-x_0}^\alpha
   - \frac12\E \norm{Y-Y^\prime}^\alpha\\
  &\quad-\E \norm{Z-x_0}^\alpha
   -\E \norm{Y-x_0}^\alpha
   +\E \norm{Z-Y}^\alpha\\
  &= \frac12\left(
     -\E \norm{Z-Z^\prime}^\alpha
     -\E \norm{Y-Y^\prime}^\alpha
     +2\E \norm{Z-Y}^\alpha
     \right)\\
  &= \frac12 MMD_{k_\alpha}^2(\mu,\nu)
\end{align*}

The expectations vanish because $Z$ and $Z^\prime$ are independent and identically distributed, hence $\E \norm{Z-x_0}^\alpha = \E \norm{Z^\prime-x_0}^\alpha$ and the same holds for $Y$ and $Y^\prime$.
The factor two does not affect whether we have a metric or not, hence MMD with the negative type kernel is a metric.
\end{proof} 

As we will see below, characteristicness is not required to prove the Bellman contraction
as long as we have a kernel like function with two required properties that also makes the MMD a metric. This is why taking a rectified kernel is justified. \\

Additionally, Nguyen et al. define the state-action supremum metric as hinted at in the introduction 
\cite{nguyen2020moment}
$$
  \MMD_{\infty,k}(\eta,\nu)
  =
  \sup_{x,a}\MMD_k(\eta(x,a),\nu(x,a)).
$$

\begin{theorem}{MMD Bellman contraction, \cite[Theorem 2]{nguyen2020moment}}{}
Assume that $k=\sum_{i\in I}c_i k_i$ where $c_i\geq0$ and every $k_i$ has the following two properties. Firstly, it is translation invariant,
$$
  k(x+c,y+c)=k(x,y)
$$
and somewhat scale invariant, i.e. for $b_{\gamma,0}(z)=\gamma z$,
$$
  \MMD_k\bigl((b_{\gamma,0})_\#\mu,
  (b_{\gamma,0})_\#\nu\bigr)
  =
  \gamma^{\alpha_i/2}\MMD_k(\mu,\nu).
$$
then, if we set
$\alpha_*:=\inf_{i\in I}\alpha_i$. The distributional Bellman operator satisfies
$$
  \MMD_{\infty,k}(\T^\pi\eta,\T^\pi\nu)
  \leq
  \gamma^{\alpha_*/2}
  \MMD_{\infty,k}(\eta,\nu).
$$
\end{theorem}

In particular, the unrectified distance kernel $k_\alpha$ satisfies the assumptions. On the other hand, the Gaussian kernel does not satisfy the scale invariance since if we look at the scaled gaussian kernel we have 
$$
k_\sigma(\gamma x,\gamma y)=\exp\left(-\frac{\norm{\gamma x-\gamma y}^2}{2\sigma^2}\right)=\exp\left(-\frac{\gamma^2\norm{x-y}^2}{2\sigma^2}\right)\neq \gamma^{\alpha/2}k_\sigma(x,y)
$$

With the contraction result in hand we can now straight forwardly define the particle DQN method. 
For a transition $(x,a,r,x^{\prime})$ and target-network parameters
$\bar\omega$, the
particle DQN target is constructed by first choosing the greedy next action
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac1N\sum_{j=1}^N
  z_j(x^{\prime},a^{\prime};\bar\omega)
$$
and then shifting the target particles:
$$
  y_j
  =
  r+\gamma z_j(x^{\prime},a^*(x^{\prime});\bar\omega),
  \qquad j=1,\ldots,N.
$$
With current particles $z_i=z_i(x,a;\omega)$, the empirical MMD loss is evaluated as
$$
  L_{\MMD}(\omega)
  =
  \frac1{N^2}\sum_{i,i^{\prime}=1}^N
  k(z_i,z_{i^{\prime}})
  +
  \frac1{N^2}\sum_{j,j^{\prime}=1}^N
  k(y_j,y_{j^{\prime}})
  -
  \frac2{N^2}\sum_{i,j=1}^Nk(z_i,y_j).
$$

and this can be differentiated through autograd with respect to the parameters of our networks that produced the samples. \\

Suprisingly and disagreeing with the theory, \cite{nguyen2020moment} have better empirical performance when we choose the gaussian kernel which means that a distance performs well under which the Bellman Operator is not a contraction. 
\subsection{SinkhornDRL}

As already stated, the Wasserstein distance is not a differentaible metric. This paper \cite{sun2022regularized} uses a regularized version which makes it work. 

\begin{definition}{Regularized optimal transport and Sinkhorn divergence}{}
For a cost function $c:\R\times\R\to\R_+$, the standard OT problem is the following minimization
$$
  \OT_c(\mu,\nu)
  =
  \inf_{\pi\in\Pi(\mu,\nu)}
  \int c(z,y)\,\pi(\mathrm dz,\mathrm dy),
$$
where $\Pi(\mu,\nu)$ is the set of couplings with marginals $\mu$ and $\nu$.
The entropic version is
$$
  \OT_c^\varepsilon(\mu,\nu)
  =
  \inf_{\pi\in\Pi(\mu,\nu)}
  \left\{
    \int c(z,y)\,\pi(\mathrm dz,\mathrm dy)
    +
    \varepsilon\KL(\pi\mid \mu\otimes\nu)
  \right\}.
$$
However, this version is not a metric anymore since for two measures that are the same, the regularized Wasserstein might be non zero (and it does not fulfill the triangle ineqality). 
This is why the paper uses what they call the debiased Sinkhorn divergence
$$
  \overline W_{c,\varepsilon}(\mu,\nu)
  =
  2\OT_c^\varepsilon(\mu,\nu)
  -\OT_c^\varepsilon(\mu,\mu)
  -\OT_c^\varepsilon(\nu,\nu).
$$
While this solves the issue of it being non zero when both entries are the same, this still does not satisfy the triangle inequality. 
\end{definition}

Based on this $\bar{W}_{c,\varepsilon}$, the paper defines the supremum metric as before
$$
  \overline W^\infty_{c,\varepsilon}(\eta,\nu)
  =
  \sup_{x,a}
  \overline W_{c,\varepsilon}(\eta(x,a),\nu(x,a)).
$$

\begin{figure}[ht]
  \centering
  \includegraphics[width=0.94\linewidth]{../Presentation/images/2026-07-01-13-37-43.png}
  \caption{Regularization controls how much 'spread out' the mass is, since we bias the optimization towards the product measure which is 'the most spread out'.}
  \label{fig:sinkhorn-regularization}
\end{figure}

\begin{theorem}{Reg. Wasserstein Bellman contraction, \cite[Theorem 4.1]{sun2022regularized}}{}
Define
$$
  \overline\Delta_\varepsilon(\gamma,\alpha)
  =
  \gamma^\alpha
  \left(
    1-\sup_{\mu,\nu}\lambda_\varepsilon(\mu,\nu)
  \right)
  +
  \sup_{\mu,\nu}\lambda_\varepsilon(\mu,\nu),
$$
where
$$
  \lambda_\varepsilon(\mu,\nu)
  =
  \frac{
    \varepsilon\KL(\pi^*\mid\mu\otimes\nu)
  }{
    \overline W_{c,\varepsilon}(\mu,\nu)
  }
  \in(0,1)
$$
and $\pi^*$ is the optimal regularized coupling. This implies
$$
  \overline W^\infty_{c,\varepsilon}(\T^\pi\eta,\T^\pi\nu)
  \leq
  \overline\Delta_\varepsilon(\gamma,\alpha)
  \overline W^\infty_{c,\varepsilon}(\eta,\nu).
$$
The rate lies between the unregularized Wasserstein rate also discussed in the book and the
regularization dominated rate:
$$
  \overline\Delta_\varepsilon(\gamma,\alpha)\in(\gamma^\alpha,1).
$$
\end{theorem}

The particle learning rule has the same Bellman target construction as
MMD-DQN. With current empirical measure
$$
  \eta_\omega(x,a)=\frac1N\sum_{i=1}^N\delta_{z_i(x,a;\omega)}
$$
and target empirical measure
$$
  \widehat\eta_{\bar\omega}(x,a,r,x^{\prime})
  =
  \frac1N\sum_{j=1}^N
  \delta_{r+\gamma z_j(x^{\prime},a^*(x^{\prime});\bar\omega)},
$$
the loss is
$$
  L_{\mathrm{RW}}(\omega)
  =
  \overline W_{c,\varepsilon}
  \left(
    \eta_\omega(x,a),
    \widehat\eta_{\bar\omega}(x,a,r,x^{\prime})
  \right).
$$
The Sinkhorn algorithm, which allows one to calculate the regularized Wasserstein distance between two measure with finite support, gives a differentiable approximation to this, which makes it usable as a loss.
The main downside of having to use this sinkhorn algorithm, is that it is computationally more expensive than standard losses and even the MMD one, but as we will it will also yield stronger result.

\begin{theorem}{Wasserstein--MMD interpolation
\cite[Theorem 1]{sun2022regularized}}{}
The regularization parameter interpolates between two geometries:
$$
  \varepsilon\to0
  \quad\Rightarrow\quad
  \overline W_{c,\varepsilon}(\mu,\nu)
  \to 2W_c^\alpha(\mu,\nu),
$$
whereas
$$
  \varepsilon\to+\infty
  \quad\Rightarrow\quad
  \overline W_{c,\varepsilon}(\mu,\nu)
  \to \MMD_{k_\alpha}^2(\mu,\nu),
  \qquad
  k_\alpha=-c.
$$
Thus the small-regularization endpoint recovers transport geometry, while the
large-regularization endpoint recovers the MMD induced by the negative cost
kernel.
\end{theorem}

\begin{proof}
The proof can be found in \cite{genevay2018learning}, the main argument is treating it as a constraint problem and looking at the dual.
  
\end{proof}
This, in a sense also shows that the sinkhornDLR paper is a strict generalization of the MMD paper. At least when taking the kernel to be $-c$.
