\begin{abstract}
These notes give an overview of some theoretical foundations behind approximation based distributional
reinforcement learning and newer methods using differentiable metrics on probability measures. 
We begin with linear value-function approximation in the standard scalar case, then we replace
scalar values by return distributions and introduce the two classic representations, quantile and categorical, of probability distributions.
Then, we go over how these representations can be used in function approximation using deep neural networks.
Finally, we cover the recent research on distributional reinforcement learning using differentiable metrics on probability measures such as the MMD distances or Sinkhorn divergence.  
\end{abstract}

\section*{Preliminaries}

The first part of these notes follow the treatment of distributional reinforcement learning
in \cite{bellemare2023distributional}. We first recall some of the preliminary definitions and results.

\begin{definition}{Finite Markov decision process and policy}{}
A finite Markov decision process is given by
$$
  (\X,\A,\xi_0,P_X,P_R),
$$
where $\X$ is a finite state space, $\A$ is a finite action space, $\xi_0$ is an
initial-state distribution, $P_X(\cdot\mid x,a)$ is the next-state kernel, and
$P_R(\cdot\mid x,a)$ is the reward distribution. A policy is a map
$$
  \pi:\X\to\p(\A),
  \qquad
  x\mapsto\pi(\cdot\mid x),
$$
and the discount factor satisfies $\gamma\in[0,1)$. The markov chain induced by $P_X$ and $\pi$ gives rises to the trajectory measure $P_\pi$.
\end{definition}

Given a policy $\pi$, the trajectory process is
$$
  X_0\sim\xi_0,
  \qquad
  A_t\sim\pi(\cdot\mid X_t),
$$
$$
  R_t\sim P_R(\cdot\mid X_t,A_t),
  \qquad
  X_{t+1}\sim P_X(\cdot\mid X_t,A_t),
  \qquad t\geq0.
$$
Starting from $X_0=x$ and then following $\pi$, define the discounted return
$$
  G^\pi(x)
  =
  \sum_{t=0}^{\infty}\gamma^tR_t.
$$

using this return distribution, one can naturally define the value function that tells us for each state, what the expected return is. 

\begin{definition}{Value function and return distribution}{}
The state-value function is the expected return
$$
  V^\pi(x)
  =
  \E_\pi[G^\pi(x)].
$$
The return distribution at state $x$ is
$$
  \eta_\pi(x)
  =
  \operatorname{Law}(G^\pi(x)).
$$
By definition, we can also write the value function as an integral using the return distribution as a measure. 
$$
  V^\pi(x)
  =
  \int_\R z\,\eta_\pi(x)(\mathrm dz).
$$
\end{definition}

Central to Reinforcement learning is the Bellman operator and its fixed point equation.

\begin{definition}{Bellman operator for scalar values}{}
For a function $V:\X\to\R$, the Bellman operator for policy $\pi$ is
$$
  (\T^\pi V)(x)
  =
  \E_{a\sim\pi(\cdot\mid x)}
  \left[
    \E\left[
      R+\gamma V(X^{\prime})
      \mid X=x,a
    \right]
  \right].
$$
Equivalently, the outer expectation samples the action from the policy and the
inner expectation samples reward and next state from the MDP. The Bellman
equation is
$$
  V^\pi=\T^\pi V^\pi.
$$
\end{definition}

There exists a stronger version of this Bellman equation, which is its distributional variant. 
$$
  A\sim\pi(\cdot\mid x),
  \qquad
  R\sim P_R(\cdot\mid x,A),
  \qquad
  X^{\prime}\sim P_X(\cdot\mid x,A),
$$
the return satisfies
$$
  G^\pi(x)
  \overset{D}{=}
  R+\gamma G^\pi(X^{\prime})
  \qquad\text{given }X=x.
$$
Taking laws gives
$$
  \eta_\pi(x)
  =
  \operatorname{Law}\left(
    R+\gamma G^\pi(X^{\prime})
    \mid X=x
  \right).
$$

\begin{definition}{Distributional Bellman operator}{}
For $r,z\in\R$, define what in \cite{bellemare2023distributional} is called the bootstrap map via
$$
  b_{r,\gamma}(z)=r+\gamma z.
$$
If $\nu\in\p(\R)$ and $Z\sim\nu$, then the pushforward
$(b_{r,\gamma})_\#\nu$ is the law of $r+\gamma Z$:
$$
  (b_{r,\gamma})_\#\nu
  =
  \operatorname{Law}(r+\gamma Z).
$$
For a return-distribution function $\eta:\X\to\p(\R)$, the distributional
Bellman operator is
$$
  (\T^\pi\eta)(x)
  =
  \E_{a\sim\pi(\cdot\mid x)}
  \left[
    \E\left[
      (b_{R,\gamma})_\#\eta(X^{\prime})
      \mid X=x,a
    \right]
  \right].
$$
The return-distribution function $\eta_\pi$ is its fixed point:
$$
  \eta_\pi=\T^\pi\eta_\pi.
$$
\end{definition}

When wanting to work with return distributions in practice, 
one needs a finite dimensional representation of these distributions. In \cite{bellemare2023distributional} multiple are introduced, the most important ones we will cover and which are used in practice are the following two. 

\begin{definition}{Finite dimensional representations of return distributions}{}
For a probability measure $\eta\in\p(\R)$, let
$$
  F_\eta(t)=\eta((-\infty,t]),
  \qquad
  F_\eta^{-1}(\tau)=\inf\{z\in\R:F_\eta(z)\geq\tau\}.
$$
The two standard representations are:
$$
  \text{categorical:}\qquad
  \eta(x)=\sum_{i=1}^m p_i(x)\delta_{\theta_i},
  \qquad
  p_i(x)\geq0,\quad \sum_{i=1}^m p_i(x)=1,
$$
and
$$
  \text{quantile:}\qquad
  \eta(x)=\frac1m\sum_{i=1}^m\delta_{\theta_i(x)},
  \qquad
  \tau_i=\frac{2i-1}{2m},
  \qquad
  \theta_i(x)\approx F_{\eta(x)}^{-1}(\tau_i).
$$
\end{definition} 
\vspace*{0.5cm}
If $\X$ is large, storing a scalar value for every state is already expensive.
In our case, we would need to store a full probability distribution for every state which is even more expensive. 
Hence, the rest of the notes which are based on \cite{bellemare2023distributional} will focus on value and action value function approximation, starting with the linear case.

\section{Linear Function Approximation}
We first discuss linear approximation for the state-value function
$$
  V^\pi:\X\to\R.
$$
This is the cleanest setting because the input is only the state. This section
follows Chapter 9 of \cite{bellemare2023distributional}.

\subsection{Function Approximation and Aliasing}

In a small state space, $V^\pi$ can be stored as a table with one number per
state. Function approximation instead shares parameters across states. This is
necessary when $\X$ cannot be enumerated and it permits generalization to states
not yet observed. The cost is \emph{aliasing}: a shared parameter changes the
prediction at several states. If two aliased states require different values,
no parameter vector represents both exactly. With bootstrapping, the resulting
error may propagate to states that are not themselves aliased.

\begin{definition}{State representation and linear value approximation}{}
Let $n\in\N$. A state representation is a mapping
$$
  \phi:\X\to\R^n,
  \qquad
  \phi(x) =
  \begin{pmatrix}
    \phi_1(x) \\ \vdots \\ \phi_n(x)
  \end{pmatrix}.
$$
For $w\in\R^n$, the linear value function approximation is
$$
  V_w(x)=\phi(x)^\top w,
$$
where each $\phi_i$ is a basis function and $\phi_i(x)$ is a feature.
\end{definition}

The model is linear in its weights and
$$
  V_{\alpha w_1+\beta w_2}=\alpha V_{w_1}+\beta V_{w_2},
  \qquad \nabla_w V_w(x)=\phi(x).
$$
For finite $\X$, collect the row vectors $\phi(x)^\top$ in a feature matrix
$\Phi\in\R^{|\X|\times n}$. Then
$$
  V_w=\Phi w,
  \qquad
  \F_\phi=\{\Phi w:w\in\R^n\}.
$$

For action values, either take $\phi:\X\times\A\to\R^n$ and
$Q_w(x,a)=\phi(x,a)^\top w$, or use a common state representation with one
weight vector per action, $Q_w(x,a)=\phi(x)^\top w_a$.

\subsection{Optimal Approximation in a Weighted Norm}

Let $\xi\in\p(\X)$ express the relative importance of the states. Define
$$
  \norm{V-V^{\prime}}_{\xi,2}
  =\left(\sum_{x\in\X}\xi(x)(V(x)-V^{\prime}(x))^2\right)^{1/2}.
$$
The best approximation to $V^\pi$ solves
$$
  \min_{w\in\R^n}\norm{V^\pi-V_w}_{\xi,2}.
$$
Let $\Xi=\operatorname{diag}(\xi(x):x\in\X)$. If $\xi$ has full support and
the columns of $\Phi$ are linearly independent, the unique solution is
$$
  w^*=(\Phi^\top\Xi\Phi)^{-1}\Phi^\top\Xi V^\pi.
$$
Thus the state weighting $\xi$ is part of the approximation problem: changing
how often states are sampled generally changes the best attainable weights.

\subsection{The Projected Bellman Operator}

In general, $V\in\F_\phi$ does not imply $\T^\pi V\in\F_\phi$. Define the
weighted orthogonal projection $\Pi_{\phi,\xi}$ by
$$
  (\Pi_{\phi,\xi}V)(x)=\phi(x)^\top w^*,
  \qquad
  w^*\in\arg\min_{w\in\R^n}\norm{V-V_w}_{\xi,2}.
$$
Approximate dynamic programming iterates
$$
  V_{k+1}=\Pi_{\phi,\xi}\T^\pi V_k.
$$
Projection removes the component of the Bellman update that the features cannot
represent. Repeated projection can compound approximation error.

The key stability result used here is the projected Bellman theorem from
\cite[Theorem~9.8]{bellemare2023distributional}.

\begin{theorem}{Projected Bellman contraction, \cite[Theorem~9.8]{bellemare2023distributional}}{}
Let $\xi_\pi$ be a fully supported steady-state distribution under $\pi$. Then
$P^\pi$ and $\Pi_{\phi,\xi_\pi}$ are nonexpansions in the
$\xi_\pi$-weighted $L_2$ norm. Consequently,
$$
  \norm{\Pi_{\phi,\xi_\pi}\T^\pi V-
  \Pi_{\phi,\xi_\pi}\T^\pi V^{\prime}}_{\xi_\pi,2}
  \leq \gamma\norm{V-V^{\prime}}_{\xi_\pi,2}.
$$
The projected operator has a unique fixed point
$$
  \widehat V^\pi
  =\Pi_{\phi,\xi_\pi}\T^\pi\widehat V^\pi,
$$
and the sharper orthogonal-projection argument gives
$$
  \norm{\widehat V^\pi-V^\pi}_{\xi_\pi,2}
  \leq\frac{1}{\sqrt{1-\gamma^2}}
  \norm{\Pi_{\phi,\xi_\pi}V^\pi-V^\pi}_{\xi_\pi,2}.
$$
\end{theorem}

The fixed point $\widehat V^\pi$ is generally not the direct best approximation
$\Pi_{\phi,\xi_\pi}V^\pi$.

\subsection{Monte Carlo and Semi-Gradient TD}

For independent state--return samples $(x_k,g_k)$, stochastic gradient descent
on $(g_k-\phi(x_k)^\top w)^2$ gives
$$
  w\leftarrow w+\alpha_k
  (g_k-\phi(x_k)^\top w)\phi(x_k).
$$

For a sampled transition $(x_k,a_k,r_k,x^{\prime}_k)$, replace $g_k$ by a
bootstrapped target. The TD error is
$$
  \delta_k
  =
  r_k+\gamma V_w(x_k^{\prime})-V_w(x_k)
  =
  r_k+\gamma\phi(x_k^{\prime})^\top w-\phi(x_k)^\top w.
$$
The semi-gradient update differentiates only the current prediction
$V_w(x_k)$, treating the bootstrap target as fixed:
$$
  w\leftarrow w+\alpha_k\delta_k\phi(x_k).
$$
Equivalently, if a fixed target vector $\widetilde w$ is used, the update is
SGD on
$$
  \frac12
  \left(
    r_k+\gamma\phi(x_k^{\prime})^\top\widetilde w
    -\phi(x_k)^\top w
  \right)^2.
$$
At a projected Bellman fixed point $\widehat V^\pi=\Phi\widehat w$, the
expected TD error is orthogonal to all features:
$$
  \E_\pi\left[
    \left(
      R+\gamma\phi(X^{\prime})^\top\widehat w
      -\phi(X)^\top\widehat w
    \right)\phi(X)
  \right]=0.
$$
This is the sample-based form of the projected Bellman equation. The
representation $\phi$ is therefore not a cosmetic choice: it determines which
Bellman fixed points are expressible.

The same idea works for action-values
$$
  Q^\pi:\X\times\A\to\R.
$$
Now the feature map takes a state-action pair,
$$
  \phi:\X\times\A\to\R^d,
$$
and the approximation is
$$
  Q_w(x,a)=\phi(x,a)^\top w.
$$
The TD error for policy evaluation becomes
$$
  \delta_t
  =
  r_t+\gamma Q_{w_t}(x^{\prime}_t,a^{\prime}_t)-Q_{w_t}(x_t,a_t),
  \qquad
  a^{\prime}_t\sim\pi(\cdot\mid x^{\prime}_t),
$$
with update
$$
  w_{t+1}=w_t+\alpha_t\delta_t\phi(x_t,a_t).
$$
We will use this action-value version below because QR-DQN and the deep
distributional algorithms are control methods: the agent must compare actions in
the same state, and this comparison is immediate from $Q(x,a)$.

\section{Distributional Value Approximation}

Distributional reinforcement learning replaces the scalar value function by a
return-distribution function. Instead of storing only the mean
$Q^\pi(x,a)=\E[G^\pi(x,a)]$, we keep the law of the return:
$$
  \eta^\pi(x,a)
  =
  \operatorname{Law}\bigl(G^\pi(x,a)\bigr).
$$
Thus
$$
  \eta^\pi:\X\times\A\to\p(\R),
$$
where $\p(\R)$ denotes probability distributions on the real line. The classical
action-value function is recovered by taking expectations:
$$
  Q^\pi(x,a)
  =
  \int_\R z\,\eta^\pi(x,a)(\mathrm{d}z).
$$

The distributional Bellman operator is most cleanly written using pushforwards.
For $r\in\R$, define the affine map
$$
  f_{r,\gamma}(z)=r+\gamma z.
$$
If $\nu\in\p(\R)$, then $(f_{r,\gamma})_{\#}\nu$ is the distribution of
$r+\gamma Z$ when $Z\sim\nu$. The distributional Bellman operator
$\T^\pi$ maps a return-distribution function $\eta$ to
$$
  (\T^\pi\eta)(x,a)
  =
  \E\left[
    (f_{R,\gamma})_{\#}\eta(X^{\prime},A^{\prime})
    \mid X=x,A=a
  \right],
  \qquad A^{\prime}\sim\pi(\cdot\mid X^{\prime}).
$$
The expectation averages over the random reward, the next state, and the next
action sampled from the policy.
The distributional Bellman equation is
$$
  \eta^\pi=\T^\pi\eta^\pi.
$$
Taking means on both sides recovers the usual Bellman equation for $Q^\pi$, but
the distributional equation is stronger: it describes the whole random return,
not only its expectation.

Just as linear TD restricts $Q$ to a class $\mathcal{Q}_\phi$, distributional
methods restrict $\eta$ to a class of approximate distributions. The quantile
family is one of the most important such choices. For a distribution $\nu$ with
cumulative distribution function $F_\nu$, define its quantile function by
$$
  F_\nu^{-1}(\tau)
  =
  \inf\{z\in\R : F_\nu(z)\geq \tau\},
  \qquad \tau\in(0,1).
$$
Choose $N$ quantile levels, usually the midpoints
$$
  \tau_i=\frac{2i-1}{2N},
  \qquad i=1,\ldots,N.
$$
An $N$-quantile approximation represents $\eta(x,a)$ by the empirical
distribution
$$
  \eta_\theta(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N \delta_{\theta_i(x,a)},
$$
where $\delta_z$ is a Dirac mass at $z$. The parameter
$\theta_i(x,a)$ is interpreted as the predicted $\tau_i$-quantile of the return
distribution at $(x,a)$.

The direct distributional analogue of linear action-value approximation is to
make each quantile location linear in the same feature vector:
$$
  \theta_i(x,a)=\phi(x,a)^\top w_i,
  \qquad w_i\in\R^d.
$$
Equivalently, with $W=(w_1,\ldots,w_N)\in\R^{d\times N}$,
$$
  \eta_W(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N
  \delta_{\phi(x,a)^\top w_i}.
$$
The scalar approximation $Q_w(x,a)$ has become a measure-valued approximation
$\eta_W(x,a)$. The same features are now asked to explain not only the average
return, but also the spread, asymmetry, and tail behavior of the return.

\section{Quantile TD}

Quantile TD applies temporal-difference learning to the quantile
parameterization. For policy evaluation, sample a transition and next action
$$
  (x_t,a_t,r_t,x^{\prime}_t,a^{\prime}_t),
  \qquad a^{\prime}_t\sim\pi(\cdot\mid x^{\prime}_t).
$$
The distributional Bellman target is represented by the $N$ target atoms
$$
  y_j
  =
  r_t+\gamma\theta_j(x^{\prime}_t,a^{\prime}_t),
  \qquad j=1,\ldots,N.
$$
The current prediction at $(x_t,a_t)$ has atoms
$$
  z_i=\theta_i(x_t,a_t),
  \qquad i=1,\ldots,N.
$$
Quantile regression uses the asymmetric absolute loss
$$
  \rho_\tau(u)
  =
  u\bigl(\tau-\1_{\{u<0\}}\bigr).
$$
The empirical Quantile TD loss is then
$$
  L(W)
  =
  \frac{1}{N}
  \sum_{i=1}^N
  \sum_{j=1}^N
  \rho_{\tau_i}(y_j-z_i).
$$
The residual $y_j-z_i$ compares an atom of the Bellman target distribution with
the predicted $\tau_i$-quantile at the current state-action pair. Minimizing this
loss moves $\eta_W(x_t,a_t)$ toward
$$
  \frac{1}{N}\sum_{j=1}^N
  \delta_{r_t+\gamma\theta_j(x^{\prime}_t,a^{\prime}_t)}
  =
  (f_{r_t,\gamma})_{\#}\eta_W(x^{\prime}_t,a^{\prime}_t).
$$

For linear quantiles, a subgradient update for each head is
$$
  w_{i,t+1}
  =
  w_{i,t}
  +
  \alpha_t
  \left(
    \frac{1}{N}\sum_{j=1}^N
    \bigl(\tau_i-\1_{\{y_j < z_i\}}\bigr)
  \right)
  \phi(x_t,a_t),
  \qquad i=1,\ldots,N.
$$
This is the exact analogue of the semi-gradient TD update:
$$
  \delta_t
  =
  r_t+\gamma Q_{w_t}(x^{\prime}_t,a^{\prime}_t)-Q_{w_t}(x_t,a_t)
  \quad\leadsto\quad
  \{y_j-z_i\}_{i,j=1}^N.
$$
The scalar TD target is replaced by a Bellman target distribution, and the
single scalar TD error is replaced by all pairwise quantile residuals.

In implementations, one often replaces $\rho_\tau$ by a quantile Huber loss.
This is the smooth loss used in QR-DQN; see the treatment in
\cite[Chapter 10]{bellemare2023distributional}. Define
$$
  \mathcal{L}_\kappa(u)
  =
  \begin{cases}
    \frac{1}{2}u^2, & |u|\leq \kappa,\\
    \kappa\left(|u|-\frac{1}{2}\kappa\right), & |u|>\kappa,
  \end{cases}
$$
and
$$
  \rho_\tau^\kappa(u)
  =
  \left|\tau-\1_{\{u<0\}}\right|
  \frac{\mathcal{L}_\kappa(u)}{\kappa}.
$$
The corresponding loss is
$$
  L_\kappa(W)
  =
  \frac{1}{N}
  \sum_{i=1}^N
  \sum_{j=1}^N
  \rho_{\tau_i}^{\kappa}(y_j-z_i).
$$
The Huber version keeps the asymmetric quantile penalty but smooths the
non-differentiability around zero, which is useful when the quantile locations
are produced by a neural network.

For control, the next action is usually selected greedily with respect to the
mean of the predicted distribution:
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac{1}{N}\sum_{j=1}^N \theta_j(x^{\prime},a^{\prime}).
$$
The target atoms become
$$
  y_j=r+\gamma\theta_j(x^{\prime},a^*(x^{\prime})),
  \qquad j=1,\ldots,N.
$$
This is the quantile analogue of replacing policy evaluation TD by Q-learning.

\section{Gateway to Deep Representations}

The linear approximation above separates representation and prediction:
$$
  \text{fixed features } \phi(x,a)
  \qquad\text{and}\qquad
  \text{linear heads } w_i.
$$
This is the useful gateway into deep distributional reinforcement learning. The
deep version keeps the same conceptual decomposition, but replaces the fixed
feature map by a learned representation. A neural network maps the observation
or state to a feature vector
$$
  \psi_\xi(x)\in\R^d,
$$
and the final layers produce a distributional prediction. In the quantile case
one may write
$$
  \theta_i(x,a;\omega)
  =
  f_i(\psi_\xi(x),a),
  \qquad i=1,\ldots,N.
$$
The return-distribution approximation becomes
$$
  \eta_\omega(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N
  \delta_{\theta_i(x,a;\omega)}.
$$

The parameter $\omega$ includes both the representation parameters $\xi$ and the
prediction heads. Linear Quantile TD is recovered as the special case in which
$\psi_\xi$ is fixed and $f_i$ is linear. Deep quantile methods instead optimize
all of $\omega$ by backpropagating through the distributional TD loss.

\section{QR-DQN}

QR-DQN is the deep control version of Quantile TD. It
uses a neural network to output $N$ quantile locations for each action:
$$
  \theta_i(x,a;\omega),
  \qquad i=1,\ldots,N,\ a\in\A.
$$
For each state-action pair, the predicted return distribution is
$$
  \eta_\omega(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N
  \delta_{\theta_i(x,a;\omega)}.
$$
The predicted scalar action-value is the mean of this empirical distribution:
$$
  Q_\omega(x,a)
  =
  \frac{1}{N}\sum_{i=1}^N \theta_i(x,a;\omega).
$$
Thus QR-DQN can still choose greedy actions in the usual value-based way, but
the value used for action selection is obtained by averaging the learned
quantiles.

As in DQN, QR-DQN uses two sets of parameters. The online network has parameters
$\omega$ and is updated by gradient descent. The target network has parameters
$\bar{\omega}$ and is held fixed for several updates before being copied from
$\omega$. For a transition
$$
  (x,a,r,x^{\prime},d),
$$
where $d\in\{0,1\}$ indicates termination, the greedy next action is selected by
the mean of the target-network distribution:
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac{1}{N}\sum_{j=1}^N
  \theta_j(x^{\prime},a^{\prime};\bar{\omega}).
$$
The target quantile atoms are
$$
  y_j
  =
  r+\gamma(1-d)\theta_j(x^{\prime},a^*(x^{\prime});\bar{\omega}),
  \qquad j=1,\ldots,N.
$$
The online prediction atoms for the sampled action are
$$
  z_i
  =
  \theta_i(x,a;\omega),
  \qquad i=1,\ldots,N.
$$
QR-DQN minimizes the pairwise quantile Huber loss
$$
  L_{\mathrm{QR}}(\omega)
  =
  \frac{1}{N}
  \sum_{i=1}^N
  \sum_{j=1}^N
  \rho_{\tau_i}^{\kappa}(y_j-z_i),
$$
with quantile levels
$$
  \tau_i=\frac{2i-1}{2N}.
$$
In a minibatch $\mathcal{B}$ sampled from replay memory, the objective is
$$
  \mathcal{L}_{\mathrm{QR}}(\omega)
  =
  \frac{1}{|\mathcal{B}|}
  \sum_{(x,a,r,x^{\prime},d)\in\mathcal{B}}
  L_{\mathrm{QR}}(\omega;x,a,r,x^{\prime},d).
$$
The target atoms are treated as constants when differentiating with respect to
$\omega$; this is the usual semi-gradient idea inherited from TD learning and
DQN.

The quantile Huber loss is important because the raw quantile loss
$\rho_\tau(u)$ is non-smooth at zero. QR-DQN uses
$$
  \mathcal{L}_\kappa(u)
  =
  \begin{cases}
    \frac{1}{2}u^2, & |u|\leq \kappa,\\
    \kappa\left(|u|-\frac{1}{2}\kappa\right), & |u|>\kappa,
  \end{cases}
$$
and
$$
  \rho_\tau^\kappa(u)
  =
  \left|\tau-\1_{\{u<0\}}\right|
  \frac{\mathcal{L}_\kappa(u)}{\kappa}.
$$
For small residuals, the loss has a squared-error shape, which gives smoother
gradients. For large residuals, it grows linearly, which prevents very large TD
errors from dominating the update. The factor
$|\tau-\1_{\{u<0\}}|$ keeps the asymmetry needed for quantile regression:
underestimation and overestimation are penalized differently depending on the
quantile level $\tau$.

\subsection*{How QR-DQN Relates to DQN}

DQN learns one scalar per action:
$$
  x \mapsto \{Q_\omega(x,a):a\in\A\}.
$$
QR-DQN learns a collection of quantiles per action:
$$
  x \mapsto
  \{\theta_i(x,a;\omega):i=1,\ldots,N,\ a\in\A\}.
$$
The scalar Bellman target
$$
  r+\gamma\max_{a^{\prime}}Q_{\bar{\omega}}(x^{\prime},a^{\prime})
$$
is replaced by the empirical target distribution
$$
  \frac{1}{N}\sum_{j=1}^N
  \delta_{r+\gamma(1-d)\theta_j(x^{\prime},a^*(x^{\prime});\bar{\omega})}.
$$
The squared TD loss is replaced by the pairwise quantile Huber loss. Action
selection remains risk-neutral unless we deliberately change it: QR-DQN chooses
actions by the mean of the predicted quantiles. The learned object, however, is
much richer than the mean.

\subsection*{Representation Learning Signal}

The representation $\psi_\xi(x)$ in QR-DQN is trained by many losses at once.
For a single transition, the network sees all residuals
$$
  y_j-\theta_i(x,a;\omega),
  \qquad i,j=1,\ldots,N.
$$
Lower quantile heads receive large gradients when the lower tail is poorly
placed; upper quantile heads receive large gradients when the upper tail is
poorly placed. Thus the shared representation is shaped not only by expected
return, but by the whole geometry of the target return distribution.

This gives a useful interpretation of the empirical strength of distributional
methods. A scalar DQN representation only needs to make the conditional mean
easy to predict. A QR-DQN representation must make many parts of the return
distribution easy to predict simultaneously. The extra prediction problem can
act as a richer training signal, even when the final policy is still selected by
the mean.

\section{Particle Distributional DQN}

QR-DQN uses particles with a special interpretation: the particle
$\theta_i(x,a)$ is tied to the fixed quantile level
$\tau_i=(2i-1)/(2N)$. MMD-DQN and SinkhornDRL keep the empirical-measure
form
$$
  \eta_\omega(x,a)
  =
  \frac1N\sum_{i=1}^N\delta_{z_i(x,a;\omega)}
$$
but treat the $z_i$ as deterministic samples of the return distribution, not
as named quantiles. The common template is:
\begin{enumerate}
  \item choose a divergence or metric $d$ between probability measures,
  \item study whether the distributional Bellman operator contracts under the
  induced supremum metric
  $$
    \bar d(\eta,\nu)=\sup_{x,a}d(\eta(x,a),\nu(x,a)),
  $$
  \item use the empirical version of $d$ as a differentiable DQN loss.
\end{enumerate}
The last point matters algorithmically. The ordinary Wasserstein distance is
mathematically natural for distributional RL, but its empirical optimization
with unrestricted particles is not as directly smooth as the losses below.

\subsection{MMD-DQN}

Let $k:\R\times\R\to\R$ be a continuous positive-definite kernel and let
$\Hcal_k$ be its reproducing kernel Hilbert space. For a probability measure
$\mu$, define the kernel mean embedding
$$
  \psi_\mu
  =
  \int k(z,\cdot)\,\mu(\mathrm dz)
  \in\Hcal_k.
$$
The maximum mean discrepancy is
$$
  \MMD_k(\mu,\nu)
  =
  \norm{\psi_\mu-\psi_\nu}_{\Hcal_k}.
$$
Equivalently, if $Z,Z^{\prime}\sim\mu$ and
$Y,Y^{\prime}\sim\nu$ are independent, then
$$
  \MMD_k^2(\mu,\nu)
  =
  \E k(Z,Z^{\prime})+\E k(Y,Y^{\prime})-2\E k(Z,Y).
$$
If the kernel is characteristic, the embedding is injective, and
$\MMD_k(\mu,\nu)=0$ implies $\mu=\nu$. Thus the MMD is then a genuine metric on
probability measures.

Nguyen et al. define the state-action supremum metric
\cite{nguyen2020moment}
$$
  \MMD_{\infty,k}(\eta,\nu)
  =
  \sup_{x,a}\MMD_k(\eta(x,a),\nu(x,a)).
$$
The contraction theorem does not hold for arbitrary characteristic kernels.
The clean theorem in \cite{nguyen2020moment} assumes kernels that are
translation invariant and homogeneous under discount scaling in the following
sense:

\begin{theorem}{MMD Bellman contraction, \cite{nguyen2020moment}}{}
Assume that the kernel is translation invariant,
$$
  k(x+c,y+c)=k(x,y)
$$
and, for $b_{\gamma,0}(z)=\gamma z$,
$$
  \MMD_k\bigl((b_{\gamma,0})_\#\mu,
  (b_{\gamma,0})_\#\nu\bigr)
  =
  \gamma^{\alpha/2}\MMD_k(\mu,\nu).
$$
For mixtures of such kernels, the distributional Bellman operator satisfies
$$
  \MMD_{\infty,k}(\T^\pi\eta,\T^\pi\nu)
  \leq
  \gamma^{\alpha/2}
  \MMD_{\infty,k}(\eta,\nu).
$$
\end{theorem}

Hence the metric-first story mirrors the Wasserstein contraction story: if the
chosen metric contracts under the affine Bellman shift and mixing does not
expand it, fixed-point arguments become available.

The important caveat is exactly the one emphasized in the presentation. The
kernel used for the clean theorem is not necessarily the kernel that performs
best empirically. Kernels such as
$$
  k_\alpha(x,y)=-\norm{x-y}^{\alpha}
$$
fit the contraction theory, whereas Gaussian kernels generally do not yield a
Bellman contraction in MMD. Nevertheless, Gaussian kernels can perform better
in experiments, so the theorem should be read as a stability result for a class
of metrics, not as a full explanation of the best empirical kernel choice.

For a transition $(x,a,r,x^{\prime})$ and target-network parameters
$\bar\omega$, the
particle DQN target is constructed by first choosing the greedy next action
$$
  a^*(x^{\prime})
  \in
  \arg\max_{a^{\prime}\in\A}
  \frac1N\sum_{j=1}^N
  z_j(x^{\prime},a^{\prime};\bar\omega)
$$
and then shifting the target particles:
$$
  y_j
  =
  r+\gamma z_j(x^{\prime},a^*(x^{\prime});\bar\omega),
  \qquad j=1,\ldots,N.
$$
With current particles $z_i=z_i(x,a;\omega)$, the empirical MMD loss is
$$
  L_{\MMD}(\omega)
  =
  \frac1{N^2}\sum_{i,i^{\prime}=1}^N
  k(z_i,z_{i^{\prime}})
  +
  \frac1{N^2}\sum_{j,j^{\prime}=1}^N
  k(y_j,y_{j^{\prime}})
  -
  \frac2{N^2}\sum_{i,j=1}^Nk(z_i,y_j).
$$
Only the terms involving current particles are differentiated with respect to
$\omega$; the target particles are fixed by the target network.

\subsection{SinkhornDRL}

SinkhornDRL starts from optimal transport and replaces the hard transport
problem by an entropically regularized one \cite{sun2022regularized}. For a
cost $c:\R\times\R\to\R_+$, define
$$
  \OT_c(\mu,\nu)
  =
  \inf_{\pi\in\Pi(\mu,\nu)}
  \int c(z,y)\,\pi(\mathrm dz,\mathrm dy),
$$
where $\Pi(\mu,\nu)$ is the set of couplings with marginals $\mu$ and $\nu$.
The entropic version is
$$
  \OT_c^\varepsilon(\mu,\nu)
  =
  \inf_{\pi\in\Pi(\mu,\nu)}
  \left\{
    \int c(z,y)\,\pi(\mathrm dz,\mathrm dy)
    +
    \varepsilon\KL(\pi\mid \mu\otimes\nu)
  \right\}.
$$
Because this regularized objective has a self-similarity bias, SinkhornDRL uses
the debiased Sinkhorn divergence
$$
  \overline W_{c,\varepsilon}(\mu,\nu)
  =
  \OT_c^\varepsilon(\mu,\nu)
  -
  \frac12\OT_c^\varepsilon(\mu,\mu)
  -
  \frac12\OT_c^\varepsilon(\nu,\nu).
$$

For $c(x,y)=\norm{x-y}^{\alpha}$, define the supremum divergence
$$
  \overline W^\infty_{c,\varepsilon}(\eta,\nu)
  =
  \sup_{x,a}
  \overline W_{c,\varepsilon}(\eta(x,a),\nu(x,a)).
$$
Sun et al. show that the Bellman operator is contractive with a factor bounded
by the following result from \cite{sun2022regularized}.

\begin{theorem}{Regularized Wasserstein Bellman contraction, \cite{sun2022regularized}}{}
Define
$$
  \overline\Delta_\varepsilon(\gamma,\alpha)
  =
  \gamma^\alpha
  \left(
    1-\sup_{\mu,\nu}\lambda_\varepsilon(\mu,\nu)
  \right)
  +
  \sup_{\mu,\nu}\lambda_\varepsilon(\mu,\nu),
$$
where
$$
  \lambda_\varepsilon(\mu,\nu)
  =
  \frac{
    \varepsilon\KL(\pi^*\mid\mu\otimes\nu)
  }{
    \overline W_{c,\varepsilon}(\mu,\nu)
  }
  \in(0,1)
$$
and $\pi^*$ is an optimal regularized coupling. Thus
$$
  \overline W^\infty_{c,\varepsilon}(\T^\pi\eta,\T^\pi\nu)
  \leq
  \overline\Delta_\varepsilon(\gamma,\alpha)
  \overline W^\infty_{c,\varepsilon}(\eta,\nu).
$$
The rate lies between the unregularized Wasserstein-type rate and the
regularization-dominated rate:
$$
  \overline\Delta_\varepsilon(\gamma,\alpha)\in(\gamma^\alpha,1).
$$
\end{theorem}

The particle learning rule has the same Bellman target construction as
MMD-DQN. With current empirical measure
$$
  \eta_\omega(x,a)=\frac1N\sum_{i=1}^N\delta_{z_i(x,a;\omega)}
$$
and target empirical measure
$$
  \widehat\eta_{\bar\omega}(x,a,r,x^{\prime})
  =
  \frac1N\sum_{j=1}^N
  \delta_{r+\gamma z_j(x^{\prime},a^*(x^{\prime});\bar\omega)},
$$
the loss is
$$
  L_{\mathrm{RW}}(\omega)
  =
  \overline W_{c,\varepsilon}
  \left(
    \eta_\omega(x,a),
    \widehat\eta_{\bar\omega}(x,a,r,x^{\prime})
  \right).
$$
The Sinkhorn algorithm gives a differentiable approximation to this quantity
for empirical measures, which makes it usable as a neural-network loss.

Finally, the regularization parameter interpolates between two geometries:
$$
  \varepsilon\to0
  \quad\Rightarrow\quad
  \overline W_{c,\varepsilon}(\mu,\nu)
  \to 2W_c^\alpha(\mu,\nu),
$$
whereas
$$
  \varepsilon\to+\infty
  \quad\Rightarrow\quad
  \overline W_{c,\varepsilon}(\mu,\nu)
  \to \MMD_{k_\alpha}^2(\mu,\nu),
  \qquad
  k_\alpha=-c.
$$
This is why the presentation treats SinkhornDRL as a bridge between
Wasserstein-style distributional RL and MMD-DQN: it keeps a transport-based
objective while making the empirical particle loss smooth enough for deep
learning.
